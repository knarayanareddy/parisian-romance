# Parisian Romance

A repository showcasing the Parisian Romance anime series project (*Le Fil Rouge*).

## Project Overview

- **Title**: Parisian Romance (*Le Fil Rouge*)
- **Description**: An anime series concept, style bible, world building, episode outlines, prompt lab, and production showcase set in Paris.

## Repository Structure

- `parisian-romance-anime-series/`
  - `src/` — React/TypeScript application source code
    - `components/` — UI components (Episodes, Production, ScarfArt, Sections, etc.)
    - `data/` — Episode storylines, world bible, and data models
    - `lib/` — Prompt generation and utilities
  - `package.json` — Vite + React + Tailwind configuration
  - `index.html` — Web entry point

## Getting Started

To run the web preview locally:

```bash
cd parisian-romance-anime-series
npm install
npm run dev
```
